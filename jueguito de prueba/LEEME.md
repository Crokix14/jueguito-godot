# NEON // LAST GUARD

Abre project.godot con Godot 4.2 o posterior y pulsa F6 en node_3d.tscn, o F5 para ejecutar el juego.

Sobrevive en una arena 3D a oleadas de drones. Entre oleadas elige daño, velocidad o curación. Los drones naranjas aparecen desde la tercera oleada y resisten más. Cada baja recupera un poco de vida.

- WASD o flechas: movimiento.
- Ratón: apuntar. Clic izquierdo mantenido: atacar.
- 1: espada (golpea un arco cercano). 2: arco (proyectiles).
- Espacio: dash con invulnerabilidad breve, recarga de 2 segundos.
- Shift: correr. Escape: pausar.

No requiere addons ni descargas adicionales. Los elementos de la arena se generan con geometría de Godot. El modelo stickman original se conserva aunque esta versión no lo utiliza.
